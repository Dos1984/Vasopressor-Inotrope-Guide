# Vasopressor & Inotrope Guide

Mobile-first bedside guide for starting and escalating vasopressors and inotropes (UK/Ireland practice): assessment, preparation, cautions, escalation (central/peripheral), drug reference and 30 practice cases.

Educational aid for trained clinicians; it does not replace local protocols or senior advice.

## Install on iPhone
Open the site in Safari, tap Share, then Add to Home Screen.
